PROJECT OVERVIEW

This autonomous robot was developed for a robotics competition conducted as part of the Tamil Nadu Robotics League.

The competition involved more than 5,000 students from Tamil Nadu, Kerala and Karnataka. The robot was developed around a lunar exploration scenario where a rover lands on the moon, collects three different samples and returns to the designated space-station area.

MISSION CONCEPT

The complete mission was designed to operate autonomously. The robot follows a predefined path, detects sample locations, picks the sample using a robotic arm, places it into a storage container and continues to the next sample.

  • Start autonomous mission
  • Follow predefined path
  • Detect sample
  • Stop at sample location
  • Pick object using robotic arm
  • Place object into storage unit
  • Continue path
  • Repeat for three samples
  • Complete return journey

HARDWARE

  • Arduino Uno
  • 5 × IR sensors
  • L298N motor driver
  • 2 × MG90S servo motors
  • 12 V lithium-ion battery
  • Buck converter
  • Custom robotic arm
  • Sample storage mechanism

CONTROL LOGIC

Four IR sensors were used for path following while a central IR sensor was used for sample detection.

When the central sensor detected an object, the robot stopped and triggered the robotic arm to pick the sample and place it inside the storage unit. After the collection process, the robot resumed autonomous path following.

The control logic was intentionally developed without a conventional PID implementation so that the system could be understood and reproduced by student teams participating in the competition.

MY ROLE

I was responsible for building and completing the prototype, including the robot hardware, sensor integration, control logic, robotic arm mechanism and autonomous operation.

After completing the robot, I also transferred the project concept and implementation approach to approximately 10–15 STEM trainers so they could guide student teams.
