PROJECT 03

AUTONOMOUS
MOBILE ROBOT

ROS 2 · SLAM · NAV2 · LIDAR · AUTONOMOUS NAVIGATION

PROJECT OVERVIEW

This project focuses on the development of an Autonomous Mobile Robot using ROS 2, combining physical robot hardware, embedded electronics and robotics software.

The project started as my final-year engineering project, where I developed the robot up to teleoperation using ROS 2. The platform was later further developed into an autonomous mobile robot with LiDAR-based mapping and navigation.

ROBOT HARDWARE

  • Raspberry Pi 4B
  • Arduino Uno
  • RPLIDAR A1
  • 2 × 12 V 100 RPM geared motors with encoders
  • Cytron motor driver
  • Differential-drive mobile platform
  • Battery and power management system

ROS 2 SOFTWARE STACK

  • ROS 2 Humble
  • Gazebo
  • RViz
  • ros2_control
  • SLAM Toolbox
  • Nav2
  • TF2
  • LiDAR integration
  • Differential-drive control

DEVELOPMENT PROCESS

The robot was first developed as a physical differential-drive platform and integrated with the embedded controller and Raspberry Pi.

ROS 2 was then used for robot control and teleoperation. A Gazebo simulation environment was also developed to understand and validate the robot model and control system.

After establishing the basic ROS 2 control system, an RPLIDAR A1 was integrated for environment sensing and mapping.

SLAM & MAPPING

SLAM Toolbox was used to build maps of the environment using LiDAR data. RViz was used to visualize the robot, laser scan, TF frames and generated map.

The mapping process helped establish the foundation for autonomous navigation and localization.

AUTONOMOUS NAVIGATION

Nav2 was integrated as the navigation framework for autonomous movement. The robot uses the generated map, localization and navigation stack to plan and execute movement toward target positions.

This work gave me practical experience in integrating the complete ROS 2 navigation pipeline rather than working with individual packages in isolation.

MY ROLE & LEARNING

I worked across the robot hardware, ROS 2 integration, simulation, robot control, LiDAR integration, mapping and navigation.

The project helped me develop a stronger understanding of how mechanical hardware, embedded controllers, ROS 2 nodes, sensors, TF, SLAM and autonomous navigation work together as a complete robotic system.

COLLABORATIVE ROBOTICS WORK

To further develop my understanding of mapping and navigation, I have also worked collaboratively with robotics teams on different robotic platforms, including work involving Unitree Go2 Pro and an A-series robotic platform.
